# Mini-PRD — Mes produits (stack)

**Onglet** : Mes produits  
**Route** : `/stack`  
**Dépend** : Produits

## Problème

Le catalogue peut être large ; l’acheteur a une sélection habituelle
(« ce que j’achète vraiment »).

## Comportement attendu

1. Marquer des produits comme « dans ma stack ».
2. Vue dédiée listant uniquement cette sélection.
3. Depuis la stack : voir prix actuel, ajouter au panier rapidement.
4. Retirer de la stack sans supprimer le produit du catalogue.

## Critère de done

- Ajouter 5 produits à la stack, en retirer 1, panier en 2 clics depuis
  la stack.
